Calibrated files for Saskatchewan applications of the Daycent Biogeochemical Process Model. Crop parameters and SOC decomposition parameters have been parameterized using crop insurance yield data 
and the Prairie Soil Carbon Balance Dataset. Based on a sensitivity analysis, not all the decomposition parameters were modified from default. Some use the values from 
Gurung et al. (2020). 

For these calibrations the sitepar.in file was modified to ensure drainage out of the bottom of the soil profile. 

Gurung, R.B., Ogle, S.M., Breidt, F.J., Williams, S.A., Parton, W.J., 2020. Bayesian calibration of the DayCent ecosystem model to simulate soil organic carbon dynamics and reduce model uncertainty. 
Geoderma 376, 114529. https://doi.org/10.1016/j.geoderma.2020.114529
